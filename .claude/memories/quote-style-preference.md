# Quote Style Preference

User prefers **single quotes** (`'...'`) over double quotes (`"..."`) for strings.

Apply this to all code written or edited for this user across all languages that support both styles (Python, JavaScript, TypeScript, etc.).

Caveats:
- Use double quotes when the string contains a single quote/apostrophe to avoid escaping (e.g., `"it's"`).
- For languages/formats that require a specific style (e.g., JSON requires double quotes), follow the format's requirements.
- If a file/project already consistently uses double quotes, match the existing style to avoid inconsistency unless asked to convert.
